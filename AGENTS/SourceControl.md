# Source Control

This file defines how agents should use source control in this repository.

- Preserve unrelated changes already present in the working tree.
- Work on the current branch unless the user explicitly requests a different branch.
- Do not create branches, open pull requests, commit, or push unless the user asks.
- Keep commits focused and use concise messages describing the outcome.
- Do not commit local scratch files or agent-specific state.
- Before committing, inspect the staged changes and avoid including unrelated files.
